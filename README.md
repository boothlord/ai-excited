# The Koi That Outgrew Its Teacup

A gigantic orange-and-white koi bursts out of a tiny porcelain teacup, riding a spiral of turquoise water into the sky while a miniature sailor surfs the splash on a paper boat. It is pure scale-play momentum: one bold silhouette, saturated colour, and a leap that is still happening. `main.ts` simply copies `image.png` to `/output/entry.png`, byte for byte, on every run.
